# ✦ Protocol Manifold — Live Mathematical Wayland Desktop Engine

A 60 FPS hardware-accelerated Cairo mathematical wallpaper and relativistic physics engine built natively for **GNOME Wayland** (GNOME 45–50).

---

## 1. One-Command Installation

    git clone https://github.com/Kaush-kk/protocol-manifold.git
    cd protocol-manifold && ./install.sh

*(Log out and log back into GNOME Wayland once after installing to initialize the compositor layer).*

---

## 2. Complete Usage & Controls Guide

### Interactive Mouse Physics on Your Desktop
* **Cursor Gravity:** Moving your mouse across the desktop warps the relativistic space-time continuum mesh in real time.
* **Left-Click (Single Click):** Launches an expanding relativistic gravitational wave that physically bends and stretches the space-time grid.
* **Left-Click & Hold (~0.3s):** Forges a spinning **Black Hole** with an accretion disk. Drag it across the screen and release to let it drift with momentum.
* **Binary Black Hole Merger & Kilonova Blast:** Spawn two or more black holes to watch them pull each other into a binary orbital inspiral, ricochet with a shockwave on first contact, and detonate in a multi-ring **Kilonova explosion**.

### Switching Mathematical Animations (`manifoldctl`)
Run any of these commands in your terminal to switch animations live in 0.1 seconds:

    manifoldctl gargantua     # Relativistic tilted black hole accretion disk & photon ring
    manifoldctl fabric        # Pure minimalist space-time gravity mesh
    manifoldctl supernova     # 130 Keplerian orbiting starlight nodes
    manifoldctl attractor     # 3D rotating chaotic Lorenz Strange Attractor ribbon
    manifoldctl pendulum      # Harmonic cymatics standing-wave interference rings
    manifoldctl fibonacci     # Golden Ratio (Phi) 240-node spiral galaxy
    manifoldctl tesseract     # 4D Hypercube stereographic projection rotating in XW/YZ space
    manifoldctl geodesic      # Celestial concentric planetary astrolabe

### Switching Color Palettes

    manifoldctl interstellar  # Warm Gargantua Gold & Champagne
    manifoldctl aether        # Celestial Ice-Blue & Deep Indigo
    manifoldctl cosmos        # Amethyst Violet & Rose-Gold
    manifoldctl monolith      # Architectural Silver & Monochrome White

### Minimalist Mathematical Sanctum (Turning the Grid Off/On)

    manifoldctl off           # Closes all grids; leaves a minimalist Golden Ratio & Infinity emblem
    manifoldctl on            # Restores your active space-time fabric

## 3. One-Command Complete Removal (Uninstall & Delete Cloned Repo)

If you want to completely uninstall Protocol Manifold, restore your default GNOME wallpaper, and delete the cloned GitHub folder in one command:

    ~/protocol-manifold/uninstall.sh && rm -rf ~/protocol-manifold
