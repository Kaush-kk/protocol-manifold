# ✦ Protocol Manifold — Live Mathematical Wayland Desktop Engine

A 60 FPS hardware-accelerated Cairo mathematical wallpaper engine built natively for **GNOME Wayland** (GNOME 45–50).

## Features
* **Interactive Relativistic Physics:** Space-time continuum grid warps dynamically around your global Wayland cursor with infinite edge overscan.
* **Left-Click Gravitational Waves:** Clicking launches an expanding relativistic wave that physically distorts the space-time fabric.
* **N-Body Binary Black Hole Collisions:** Hold left-click (~0.3s) to forge spinning black holes. Spawn two or more to watch them enter a relativistic binary inspiral, ricochet with a shockwave on first contact, and detonate in a **Kilonova explosion**.
* **8 Mathematical Modes:** `gargantua`, `fabric`, `supernova`, `attractor` (3D Lorenz), `pendulum`, `fibonacci`, `tesseract` (4D Hypercube), and `geodesic`.
* **4 Curated Cosmic Palettes:** `interstellar`, `aether`, `cosmos`, and `monolith`.
* **Minimalist Mathematical Sanctum (`manifoldctl off`):** Closes all grids and renders a breathing Golden Ratio Vesica Piscis and Infinity Lemniscate on pure obsidian.

## One-Command Install

    git clone https://github.com/Kaush-kk/protocol-manifold.git
    cd protocol-manifold && ./install.sh

## Usage

    manifoldctl {gargantua|fabric|supernova|attractor|pendulum|fibonacci|tesseract|geodesic}
    manifoldctl {interstellar|aether|cosmos|monolith}
    manifoldctl {on|off}
